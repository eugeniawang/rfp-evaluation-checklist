RFP Evaluation Criteria Checklist

Give Claude a public-sector RFP. Get back a checklist of how the agency will score you and what gets a proposal thrown out, in the RFP's own words, with every line linked to the page and line it came from.

Try the demo Get the folder on GitHub

How you'll be scored

Every item the RFP scores, its points, what to provide, and what the scorer looks for. Quoted, never paraphrased.

What gets you thrown out

Every rule that can disqualify a proposal before anyone scores it: late, missing a form, over the page limit, non-responsive.

Every line clickable

Click a box like Page 14, line 15 to see the exact words in the RFP. Where the RFP is silent, the cell says not in source.

How to use it

  1. Claude Code: open the folder, put the RFP PDF in it, and say Translate rfp.pdf.
  2. claude.ai Projects: add the folder's files to a project with code execution turned on, attach the RFP, and ask for the translation.
  3. Command line: the steps are in the README: extract, check, render.
